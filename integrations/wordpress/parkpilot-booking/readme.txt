=== ParkPilot Booking ===
Requires at least: 5.8
Tested up to: 6.6
Stable tag: 1.0.0
License: GPLv2 or later

Adds the ParkPilot price check and booking box with the [parkpilot] shortcode.

== Installation ==
1. Upload the parkpilot-booking folder to wp-content/plugins (or upload the zip under Plugins > Add New).
2. Activate it, then open Settings > ParkPilot and enter your ParkPilot address, public key (pk_...), lot ID, tenant slug and lot slug.
3. Add [parkpilot] to any page. In ParkPilot, add your website address to the key's allowed origins.

== Security ==
Use only the public key (pk_...). The plugin refuses secret keys (sk_...).
